# Dữ liệu gốc

`mnist.npz`: https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz

60.000 ảnh train, 10.000 ảnh test, uint8, 28x28. Chỉ đọc; SHA256 của lần chạy có trong `result/full/config.json`. Không đổi ảnh/nhãn tại đây. Dữ liệu không đưa vào Git theo mặc định; khi nộp ZIP có thể kèm file để chạy offline.
